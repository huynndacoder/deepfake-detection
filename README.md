## Problem Statement

With the rapid advancement of generative models such as StyleGAN3, synthetic
face images have become nearly indistinguishable from real ones. This project
builds and compares multiple machine learning approaches — from a classical
SVM baseline to fine-tuned deep neural networks — to automatically detect
AI-generated faces.

## Dataset

- **Source:** Kaggle — 10,000 Real vs Fake Faces (StyleGAN3)
- **Generator:** StyleGAN3
- **Size:** 20,000 images (10,000 real + 10,000 fake)
- **Split:** 70% train / 15% validation / 15% test (stratified)
- **Raw images and trained model weights are not tracked by Git** (see `.gitignore`).
  Download the dataset from Kaggle and place it under `data/raw/` before running any notebook.

## Results

Test set: 3,000 images (stratified 15% holdout). Evaluated with `05_error_analysis.ipynb`.

| Model | Accuracy | Precision | Recall | F1-score | ROC-AUC |
|-------|----------|-----------|--------|----------|---------|
| SVM + HOG | 0.7230 | 0.7237 | 0.7213 | 0.7225 | 0.8007 |
| Custom CNN | 0.9343 | 0.9201 | 0.9513 | 0.9354 | 0.9783 |
| MobileNet | 0.9673 | 0.9661 | 0.9687 | 0.9674 | 0.9937 |

**Key takeaway:** MobileNet Transfer Learning achieves the best performance (96.7%
accuracy, 0.994 AUC), confirming that ImageNet-pretrained features transfer well
to deepfake detection on StyleGAN3 faces.

## Streamlit Web App

An interactive Grad-CAM web app (`src/app.py`) is available for real-time
deepfake detection:

```bash
streamlit run src/app.py
```

Features:
- Upload an image for instant classification (real vs. fake)
- Grad-CAM heatmap overlay showing what the model focused on
- Confidence score with adjustable threshold
- Per-layer activation statistics
- Model selection (auto-discovers available checkpoints in `models/`)
